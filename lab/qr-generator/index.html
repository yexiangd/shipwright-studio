Heads up: these colors are low-contrast and may scan poorly on some phones. Dark code on a light background works best.

Good to know

  • Private by design. The QR code is generated by JavaScript running on this page — your text is never uploaded anywhere. View-source it if you like.
  • Error correction lets a code still scan when partly obscured or dirty. M is the sweet spot; use H for codes printed small or on rough surfaces.
  • Keep a quiet zone (the blank margin) around the code — this tool adds one automatically on export.
  • Wi-Fi codes use the WIFI:T:…;S:…;P:…;; format that iOS and Android cameras recognize; contact codes use the vCard format.
