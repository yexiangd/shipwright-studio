How it works

  • The deck — every quote in the active theme is shuffled once, then dealt in order. Nothing repeats until the whole deck is spent, then it reshuffles.
  • Quote of the day — the date seeds a small random generator, so the same day always picks the same quote, for everyone.
  • The sources — every line is a real, attributed aphorism, from Marcus Aurelius to Naval Ravikant. No invented attributions, no paraphrases passed off as quotes.
