Entity Codec

Entity Codec is a free online tool that encodes text into HTML entities and decodes HTML entities back to readable text — type in either pane and the other updates instantly, right in your browser. Nothing you type is sent anywhere.

Safe by design: decoded output is rendered as plain text, never injected as HTML, so pasted markup can never execute on this page.
