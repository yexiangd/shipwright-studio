Tab Search

Tab Search is a free online tool that finds any open tab by title or URL, so you can jump straight to the tab you need instead of hunting through windows. Type a few letters, pick a result with the arrow keys, and press Enter — the prototype below works exactly like the extension would, on sample data.

Prototype demo: a web page cannot read your real browser tabs, so this demo searches a realistic sample dataset of 18 tabs across 3 windows. No data leaves this page.

How it works

Search matches tab titles and URLs. A title match ranks above a URL-only match, and a match at the start of a title ranks above one buried in the middle — so the tab you are thinking of usually lands first. Results stay grouped by window, and the extension version would read your real tabs through the browser's tab API and switch to one instantly.
