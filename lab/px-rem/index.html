How it works

  
    
    
  • The formula — rem = px ÷ base and px = rem × base. At the default 16px base, 20px is 1.25rem.
    • 
    
  • Why rem — rem units scale with the reader's root font size, so a layout set in rem respects the browser's text-size setting while px stays fixed.
    • 
    
  • Rounding — results are rounded to at most 4 decimal places, with trailing zeros trimmed, so 15px at 16 is 0.9375rem and 1px is 0.0625rem.
