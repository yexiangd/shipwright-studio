How it works

Kept, dropped, tidied. Headings, paragraphs, bold, italic, links, images, lists, code, quotes and tables are converted; scripts, styles, navigation, headers, footers and forms are stripped, along with every class, id and inline style. Whitespace is normalised and HTML entities are decoded, so the result reads like Markdown written by hand.

No libraries, no server. The converter is a small hand-written HTML tokenizer and renderer in plain JavaScript — the same code is unit-tested with node, and it runs entirely in your browser. Paste a fragment or a whole page; malformed or unclosed tags are handled gracefully instead of crashing.

Your text stays yours. Nothing is uploaded, stored or tracked. Copy the result, download it as a .md file, or check it in the Preview tab before you use it.
