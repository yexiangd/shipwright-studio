Hash Lab

Hash Lab is a free online tool that computes SHA-1, SHA-256, SHA-384 and SHA-512 digests for text or files, entirely in your browser — nothing is uploaded, so your input never leaves your device.

Why no MD5?

MD5 is not exposed by the Web Crypto API, so this tool only offers the SHA family — SHA-1, SHA-256, SHA-384 and SHA-512. Hashing is one-way: the same input always produces the same digest, and the digest cannot be turned back into the input. That is what makes a digest useful for verifying a file or a password check, and useless for recovering the original.
