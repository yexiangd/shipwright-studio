URL Codec

URL Codec is a free online tool that percent-encodes and decodes URLs and query strings, shows exactly what changes between encodeURIComponent and encodeURI, and turns any query string into an editable parameter table — entirely in your browser, so nothing is ever uploaded.

Encode / decode
Component = encodeURIComponent: encodes ? & = / # too — for values. Full URL = encodeURI: keeps URL structure intact, encodes only spaces and Unicode.
