Coin Flip

Coin Flip is a free online tool that flips a virtual coin with crypto-grade 50/50 odds — spin the coin, call it before it lands, or run a best-of series to settle a decision properly.

Fair by construction. Each flip is decided by crypto.getRandomValues — exactly 50/50, fixed before the coin stops spinning. The animation is presentation only; the coin never changes its mind.

How fairness works

  • Each flip draws one 32-bit value from crypto.getRandomValues (with a Math.random fallback only if the crypto API is unavailable). Values below half the range land Heads; the rest land Tails — exactly 50/50, no weighting, no memory.
  • The result is decided the instant you flip, before the coin starts turning. The spin is a fixed number of full turns plus the half-turn needed to land on the pre-decided face, so the animation can never change the outcome.
  • Flips, streaks, call accuracy and history live in localStorage only. Resetting clears them from this browser and nothing else.
