How it works


    

  • Offset moves the shadow sideways and down; negative values move it up or left.
    • 

  • Blur softens the shadow edge — 0 gives a hard edge, higher values fade it out.
    • 

  • Spread grows (positive) or shrinks (negative) the shadow before blurring.
    • 

  • Inset draws the shadow inside the element instead of outside it.
    • 

  • Opacity controls how dark the shadow colour reads against the backdrop.
