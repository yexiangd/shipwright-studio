How it works

Code 128 is the workhorse barcode of logistics and retail: it encodes the full printable ASCII range, is compact, and carries a built-in checksum, so a scanner can tell a misread from a good read.

The checksum. Every barcode ends with a check character — the start-code value plus each data value multiplied by its position, all modulo 103. If a single bar is damaged, the check fails and the scanner refuses the read instead of guessing.

Code 128-C for digits. Long runs of numbers are packed two digits per symbol, which makes numeric codes like 4006381333931 almost half as wide. This page switches to Code 128-C automatically for digit runs of six or more.

Nothing leaves your browser. The encoder, the renderer and the file downloads all run locally on this page — your text is never sent anywhere.
