What is a UUID?

A UUID (universally unique identifier) is a 128-bit label like 6ba7b810-9dad-11d1-80b4-00c04fd430c8. The version digit (the first character of the third group) tells you how it was made: …-4… is random, …-1… embeds a timestamp, …-7… starts with Unix milliseconds so ids sort chronologically. With 2¹²² possible v4 values, collisions are for all practical purposes impossible — which is why UUIDs work as database keys, request ids, and filenames without a central coordinator.
