OG Preview

OG Preview is a free online tool that shows how your link will look when shared on X, Slack, and iMessage — before you post it. Type a URL, title, and description, pick an image, and see each platform's link card update live, with character-count guidance and a copyable set of meta tags.

Previews are rendered from the values you type — this page never fetches the URL, so real cards may differ slightly (platforms cache images and sometimes rewrite titles).
