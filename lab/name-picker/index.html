Name Picker

Name Picker is a free online tool that draws a fair random winner from any list of names — for classrooms, raffles and giveaways — with a no-repeat mode so everyone gets a turn, and a winner history to keep the draw honest. Everything runs in your browser; your names are never sent anywhere.

    How it works

    Every name in the pool has exactly the same chance. The final pick is made with the Web Crypto API (crypto.getRandomValues) — the same source of randomness browsers use for security — not with a plain pseudo-random call, so the draw can't be nudged toward any name.

    With Don't repeat winners on, each name can only win once until the whole pool has had a turn; then the pool resets automatically and the next draw starts fresh. Turn it off and every draw is independent — any name can win twice in a row.

    Names are trimmed, blank lines are ignored, and duplicates are collapsed, so pasting a roster straight from a spreadsheet just works. Nothing is uploaded or stored: close the tab and the list is gone.
