JSON Viewer

JSON Viewer is a free online tool that turns raw JSON into a collapsible, searchable tree. Paste an API response, a config file, or a log payload and explore it node by node — expand what matters, search for any key or value, and copy the path of anything you find. Everything runs in your browser; nothing is uploaded.

Valid JSON renders here as a collapsible tree. Click any key to copy its path.

How it works

  • Click a ▸ caret to expand a container, or ▾ to collapse it. Expand all and Collapse all do the whole document at once.
  • Click any key (or array index) to copy its JSON path, like $.store.book[0].title.
  • Search matches keys and values, highlights them, and hides branches with no match.
  • Private by design: parsing and rendering happen entirely in your browser — your JSON never leaves this page.
