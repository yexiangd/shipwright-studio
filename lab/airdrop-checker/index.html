Airdrop Checker Template

Airdrop Checker Template is a free online tool that checks a wallet address against an editable set of token-airdrop eligibility rules and shows an eligible or not-eligible verdict with a per-rule pass/fail breakdown — so builders can prototype an airdrop claim page and anyone can see how eligibility rules work, using sample data only.

DEMODemo only — sample data, no real chain connection. Stats are generated in your browser from the address and are not real balances.

How the demo works

Every stat is derived deterministically from the address itself with a small hash function (FNV-1a), so the same address always produces the same balance, holding period, transaction count, and first-activity date — try checking the same address twice. A stat exactly equal to its threshold passes. The snapshot rule passes when the address’s first activity is on or before the snapshot date. None of this touches a blockchain: there is no RPC call, no wallet connection, and no real airdrop to claim.
