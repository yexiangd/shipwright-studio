# 2048 — Build Spec

## Concept

2048 is the classic tile-sliding puzzle rebuilt for the browser as a
dependency-free static page: slide numbered tiles with arrows or a swipe,
merge matching pairs, and chase the elusive 2048 tile. One page, one game —
no installs, no accounts. Score and best score persist locally, and the game
is fully playable with keyboard on desktop or swipe on mobile.

## Feature list

1. 4×4 board rendered as a CSS grid; tiles positioned with CSS transform
   transitions for smooth sliding and a pop animation on merges.
2. Keyboard input: arrow keys + WASD; touch swipe on the board (≥24px
   threshold); page doesn't scroll when swiping on the board
   (`touch-action: none`, arrow-key default prevented).
3. Move/merge logic per direction: each tile merges at most once per move;
   after every *valid* move exactly one new tile spawns (90% a `2`, 10% a
   `4`) in a random empty cell.
4. Score = sum of merged tile values; `+N` delta animation on each merge.
   Best score persisted in `localStorage`, shown next to live score.
5. Win at 2048: celebratory overlay ("You made 2048!") with a "Keep going"
   button so the player can chase higher tiles.
6. Game over: no empty cells AND no adjacent equal tiles in any direction →
   overlay with final score/best and a Restart button.
7. New Game button restarts at any time; board resets to two starting tiles.
8. Tile color ramp keyed to value: dark surface tiles through a warm
   brass-to-gold ramp; the 2048 tile gets the signature brass glow.

Out of scope: undo, 5×5 or other board sizes, sound effects, online
leaderboard, AI solver.

## Design

Top to bottom: topbar (← Lab / Shipwright Studio brand / best-score line),
`h1` "2048", quotable definition paragraph (GEO), stats row (Score / Best
pills), board panel (max ~480px square, surface `#10141a`, 8px gaps),
controls row (New Game button + "Arrows / WASD · swipe on mobile" hint),
footer note ("Best score lives on this device only").

Visual treatment: dark `#0a0c0f`, Fraunces headings, brass `#d2a24c` accent.
Empty cells are recessed (`#161b22`-ish); numbered tiles use a warm ramp
from slate through tan to brass glow at 2048+. Font sizes scale with tile
value; mono font for score pills. Generous whitespace around the board.

Mobile: board scales to viewport width (`width: 100%`); swipe detection on
the board; stats wrap; no on-screen arrows needed (swipe suffices).

States: idle/start (board shows two tiles; game live immediately on load —
no start overlay needed for a puzzle), active, win overlay (dismissable,
"Keep going"), game-over overlay (score/best, "Try again").

## Acceptance criteria

- A user can slide tiles with arrow keys, WASD, and touch swipe; merges
  happen correctly (a tile merges at most once per move) and one new tile
  spawns only after a valid move.
- Score accumulates merged values; best score persists across reloads and a
  `+N` delta animates on merges.
- Reaching a 2048 tile shows the win overlay with a working "Keep going"
  button; an unplayable board shows the game-over overlay with restart.
- Exactly one `h1`, canonical link, meta description, and a WebApplication
  JSON-LD block are present; no external JS dependencies.
- No email addresses, API keys, or secrets in the file.
